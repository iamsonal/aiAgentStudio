# Contributing to Pluto

## Sign the contributor license agreement

Before a pull request can be merged, each author must sign the
[Pluto Contributor License Agreement](CLA.md) (CLA).

1. Open your pull request.
2. The CLA check posts a comment with a link to the agreement. Read it.
3. Post this comment on the pull request:

    ```
    I have read the Pluto CLA and I agree to it.
    ```

4. The CLA check turns green. If it does not, post `recheck` on the pull
   request.

You sign once. The signature covers your later pull requests. If you
contribute for your employer, make sure they allow it before you sign.

You keep the copyright to your work. The CLA lets the maintainer release
it under other licenses as well as the AGPL, for example a commercial
license. Every release made under the AGPL stays under the AGPL.

## Before you open a pull request

1. Keep each source file's copyright and license notice.
2. Give each new source file in `force-app`, `pluto-console`,
   `pluto-model-adapters`, or `test` the same notice. Copy it from any
   existing file in that folder.
3. Report security problems as [SECURITY.md](SECURITY.md) describes, not in
   a pull request.
